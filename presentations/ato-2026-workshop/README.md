## Rebuild

```
cd presentations/ato-2026-workshop
npm install            # once; installs pptxgenjs
node build.js          # writes ato-2026-workshop.pptx and speaker-notes.md
```

The build prints a warning if any note is over 140 words.

PDF: LibreOffice is not installed on this Mac (the `soffice` wrapper in Homebrew points at a missing app), so the PDF is exported with Keynote through AppleScript:

```
osascript -e 'set src to POSIX file "<abs>/ato-2026-workshop.pptx"' \
  -e 'set dst to POSIX file "<abs>/ato-2026-workshop.pdf"' \
  -e 'tell application "Keynote"' -e 'set d to open src' -e 'delay 4' \
  -e 'export d to dst as PDF' -e 'close d saving no' -e 'end tell'
pkill -x Keynote
```

Thumbnails: `rm previews/slide-*.png && pdftoppm -png -r 60 ato-2026-workshop.pdf previews/slide`.

Deck text for review: for each page N, `pdftotext -layout -f N -l N ato-2026-workshop.pdf -`, strip the `NN / 85` footer counter from the end of any line, collapse runs of blank lines, and append the matching note from `speaker-notes.md` under `Notes:`. That is what `deck-text.md` holds.

If LibreOffice is installed later, `soffice --headless --convert-to pdf ato-2026-workshop.pptx` works too; expect small font-metric differences between the two renderers.

## The Tufte pass (October 15, evening)

Mark's note on the previous version: "make the deck less crowded and more visually interesting. Make Tufte proud," and "use approachable understandable language, not vague descriptors." This version is that pass, plus the new slides the updated run of show asks for. 73 slides became 85.

### Rules applied to every slide

- **Data-ink.** Boxes, pills, accent bars, and eyebrow prefixes that carried no meaning are gone. Boxes remain only where 2–3 parallel items need alignment (the six tour tiles, the eight theme tiles, the six color chips, the skill-file drawing) or where the box itself means something (the dark prompt card means "type this"; the dark diff block is a diff). Everything else is plain text with air around it: definition lists (`defs`), numbered steps (`numbered`), plain columns (`cols`).
- **One idea, one visual.** Where a slide was a list of steps or relationships, it is now drawn with pptxgenjs shapes in the brand colors. See the list below.
- **Typography carries hierarchy.** Title, one supporting line (`lede`, usually the slide's "Done when:" gate), then the visual. Body text is 16pt or larger on teaching slides; nothing on any slide is under 11pt except the 9pt footer counter (checked by script: the only `fontSize` under 11 in `build.js` is the counter). At most four lines of body on a non-reference slide.
- **Prompts.** One prompt card per slide, prompt text at 14pt or larger (16pt where it fits). Slides that had two prompts were split: the Step 5 lock-in (portable / v0) and the Track B plan / build prompts. No prompt needed its own slide beyond those two splits; the longest (the v0 first-generation prompt) fits a full-width card at 14pt.
- **Reference slides** (the two day tables, the skills menu, the four game extensions, the own-theme form, the checkpoint ladder, the eight theme tiles) are denser and their notes say "point, don't read." They got taller rows (0.42–0.62") and 11pt table headers. The eight-theme slide dropped the attack, counter, and color columns (the notes point to `docs/tic-tac-toe-variants.md`); the two day tables kept both columns because the notes use the deliverable rows.
- **The footer strip.** The six-pill lifecycle strip is gone from the footer. In its place: a text-only "you are here" row (`here()`), drawn only when a step is active. On slides with no active step nothing is drawn. The sticky legend survives only on hands-on slides, as one 12pt line.
- **Language.** Titles and lines were rewritten where a first-timer could not turn them into an action: "This is a fluid day" became "Behind? Grab a checkpoint. Stuck? Say one sentence."; "Stuck? Grab a checkpoint." became "Stuck? Grab the rung for where you are."; "Same loop, eight looks" now says "Renaming is all a theme does." Notes were searched for "the room," "the vibe," "as needed," "appropriate," and "leverage": none present.
