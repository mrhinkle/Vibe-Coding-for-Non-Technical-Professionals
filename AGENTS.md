# Instructions for assistants using this course

Read `AI-START.md` first, then `START-HERE.md`. These are the AI tutor entry point and student navigation guide for Vibe Coding for Non-Technical Professionals.

When helping a student, treat this repository as reference material. Build the student's website and game in two separately identified learner-owned projects. Use the relevant lesson and SKILL.md one checkpoint at a time. Follow the student's existing authorizations and be explicit about unavailable tools, untested behavior, and publication.

When the user explicitly asks to update the course repository, edit the requested course materials here. Preserve the 360-minute, two-project core agenda and the distinction between the current guides and the legacy presentation. Keep `course-map.json`, entry points, generated course pack, and illustrated-guide editions consistent when their source content changes. Check local links and skill metadata; render and visually inspect any changed PDF. Do not claim learner workflows were rehearsed unless they were actually run.

For learner-project instructions, use `templates/AGENTS.md` rather than copying this course-maintainer file. Native agent support is optional; ordinary chat can use the same instructions through file upload or pasted text.

Multiple agents may handle independent requested work when supported. Give each a bounded task and an isolated writing directory. Use a coordinator to integrate changes and a read-only reviewer on the exact version. Never have parallel writers editing the same working directory, and never treat multiple role labels as proof of independent review. Additional vendor access or data sharing requires the user's authorization.
