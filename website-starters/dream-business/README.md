# Good Company creative studio starter

A charcoal-and-lime studio concept with large editorial typography, three services, and a practical project checklist. It is one offline HTML page with embedded CSS and original SVG artwork. It needs no installation or network access.

## Open it

Open `index.html` in your browser. **Explore the project checklist** moves to three questions a visitor can answer in their own notes. This is a real on-page destination, not a pretend contact form. No information is collected or sent.

## Three customization tasks

1. Rename the studio and rewrite the headline and introduction around a specific audience.
2. Replace the sample services with three clearly described things your imagined business could do. Do not add fabricated clients, results, or testimonials.
3. Adapt the checklist to your audience while preserving its `id="checklist"` destination. Keep it informational unless a separate working feature is deliberately added later.

The `CUSTOMIZE` comments identify the main edits, and CSS variables control the palette. Save a working copy before changes. Check the main action, keyboard focus, navigation, and phone-sized layout afterward. Keep the fictional label for invented content; hosting a real commercial site is a separate plan decision.
