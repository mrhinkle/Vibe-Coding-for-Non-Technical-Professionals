# Captain Pickles pet starter

A playful lilac-and-orange page about an imaginary dog, with an original inline SVG portrait, a daily routine, and favorite things. It is a single offline HTML file with embedded CSS and no external images, scripts, fonts, or installation.

## Open it

Open `index.html` in your browser. **Follow a dog's day** moves to the three-part routine. The Favorites navigation link reaches the illustrated favorites list. No photographs are implied or fetched; the portrait and small icons are original drawings inside the file.

## Three customization tasks

1. Change the name, personality, introduction, and small facts. Use invented details or information you are comfortable sharing if you later publish a real pet's page.
2. Rewrite the morning, afternoon, and evening routine. Preserve `id="routine"` so the main button still works.
3. Replace the favorite things and adjust the palette. Ask the chatbot to preserve the original SVG's accessibility labels, or update those labels accurately if changing the drawing.

Search for `CUSTOMIZE` comments. Keep a working copy, then check the actual file's main action, all links, keyboard focus, and narrow layout after changes. Retain the fictional-project footer for the invented Captain Pickles example.
