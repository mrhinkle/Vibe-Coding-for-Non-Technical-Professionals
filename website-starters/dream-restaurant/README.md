# Moonlight Noodle Club starter

A warm, illustrated restaurant concept with a sample menu and a short story. This is one standalone page with embedded CSS and original inline SVG. It uses no network resources, forms, framework, or installation.

## Open it

Open `index.html` with your browser. Keep your own copy before editing. The expected main action is **Explore the sample menu**: it moves to the three fictional dishes in the menu section. The navigation and Back to the top links stay on this page.

## Three customization tasks

1. Change the restaurant name, introduction, and short story. Keep the fictional-project label while using invented content.
2. Replace the three sample dishes and their descriptions. Preserve the menu section's `id="menu"` so the main action still reaches it.
3. Change the color variables near the top of the CSS. Check that words, links, and keyboard focus remain easy to see.

Search for `CUSTOMIZE` comments to find the main editing points. After each change, reopen the actual file, activate the menu link, use Tab to check keyboard focus, and inspect both a narrow phone-sized view and a wide laptop view. No booking, ordering, or payment service is connected.
